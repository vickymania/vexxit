# VEXXIT

A Minecraft 1.12.2 modpack for the Technic Launcher, by [vexed.works](https://vexed.works).
Built on the classic tech/magic 1.12.2 mod lineup, with extra AE2 add-ons (NAE2, AE2 Fluid
Crafting, MekEng, PackagedAuto), QuarryPlus, Dimensional Doors, Storage Drawers and more.

## ClaudeCraft

VEXXIT ships a 1.12.2 port of [ClaudeCraft](https://github.com/west3436/claudecraft) (MIT):
Claude inside CC: Tweaked computers and turtles. Claude Code runs on the PC of the player who
starts it, with that player's own Claude login, so nobody runs on someone else's account.
Needs [Claude Code](https://claude.com/code) and [Bun](https://bun.sh) on your own PC.
